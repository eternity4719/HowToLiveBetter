# 追加：第 7 节第 22 条，被欠工钱先分清雇你的是谁（issue #60）

2026-10-01。issue #60 指出第 7 节第 2 条（投诉劳动监察、申请劳动仲裁）整条以劳动关系为前提，雇人的是自然人时这两条路走不了，应当去法院。追加在节末，没有插在中间，免得后面的条号整体顺延。

## 没有照收的部分

- 读者草稿把「在小作坊做事」和「给朋友个人帮忙」归成一类，结论都是「劳动监察和仲裁不受理，走法院」。小作坊这一半与原文不符。无照经营的作坊、店铺仍是用人单位：劳动合同法第九十三条要求该单位或者其出资人支付劳动报酬；法释〔2020〕26 号第二十九条要求把用人单位或者其出资人列为当事人，也就是照样能仲裁；劳动保障监察条例第三十三条明文把无照用工纳入劳动保障监察。按草稿写，会把本来能走免费路子的人支去打官司。
- 草稿标题是「给个人干活前先看对方有没有营业执照」。有没有执照不是分界线，分界线是对方是不是在经营。条目标题和成本栏据此改写成三问：是不是在做生意、活是不是转包下来的、是不是给家里干活。
- 草稿收益量级记「大」。本条的收益是选对路、少白跑一趟，欠款本身多为数百到数千元，按金钱口径的阈值记「中」。

## 收进来的部分

- 自然人不是用人单位（劳动合同法第二条）。
- 司法解释列明的三类非劳动争议：家庭或者个人与家政服务人员、个体工匠与帮工学徒、农村承包经营户与受雇人。
- 包工头那一支：劳动合同法第九十四条的连带责任，保障农民工工资支付条例第三十六条的建设单位或总包清偿。
- 读者建议的「第 7 节第 2 条备注里加一句边界说明和交叉引用」照做了；第 8 节第 12 条备注里原有的实习生那句也补了指路。

## 1. 劳动合同法
- URL：<https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193025/content.html>
- 原文：第二条「中华人民共和国境内的企业、个体经济组织、民办非企业单位等组织（以下称用人单位）与劳动者建立劳动关系……适用本法」。第九十三条「对不具备合法经营资格的用人单位的违法犯罪行为，依法追究法律责任；劳动者已经付出劳动的，该单位或者其出资人应当依照本法有关规定向劳动者支付劳动报酬、经济补偿、赔偿金；给劳动者造成损害的，应当承担赔偿责任。」第九十四条「个人承包经营违反本法规定招用劳动者，给劳动者造成损害的，发包的组织与个人承包经营者承担连带赔偿责任。」

## 2. 法释〔2020〕26 号
- URL：<https://www.court.gov.cn/fabu/xiangqing/282121.html>
- 原文：第二条「下列纠纷不属于劳动争议：……（四）家庭或者个人与家政服务人员之间的纠纷；（五）个体工匠与帮工、学徒之间的纠纷；（六）农村承包经营户与受雇人之间的纠纷。」第二十九条「劳动者与未办理营业执照、营业执照被吊销或者营业期限届满仍继续经营的用人单位发生争议的，应当将用人单位或者其出资人列为当事人。」

## 3. 劳动保障监察条例
- URL：<https://www.gov.cn/gongbao/content/2004/content_63042.htm>
- 原文：第三十三条「对无营业执照或者已被依法吊销营业执照，有劳动用工行为的，由劳动保障行政部门依照本条例实施劳动保障监察，并及时通报工商行政管理部门予以查处取缔。」

## 4. 保障农民工工资支付条例
- URL：<https://www.gov.cn/gongbao/content/2020/content_5469641.htm>
- 原文：第三十六条「建设单位或者施工总承包单位将建设工程发包或者分包给个人或者不具备合法经营资格的单位，导致拖欠农民工工资的，由建设单位或者施工总承包单位清偿。」
