# 追加：第 19 节第 17、18 条，离职证明与离职补偿的个税

2026-10-01。两条都追加在节末，没有插在中间，免得后面的条号整体顺延。写之前 grep 过全书，「离职证明」「一次性补偿收入」「164 号」都没有现成条目。顺手在第 4 条（被裁先算清 N）备注里指向第 18 条，在第 8 条（离职前存证据）备注里指向第 17 条。节首引言把「最后七条讲职业病和工伤」改成「接着七条」，并补了一句节末三条讲什么（原来的说法在第 16 条加进来之后就已经不准了）。第 7 节第 1 条（失业保险金）这一轮没有改，那边还没有指回第 17 条。

## 1. 劳动合同法（第五十、八十九、九十一条）
- URL：<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf74d7106b3>（国家法律法规数据库，经 API 下载 docx 逐字核对）
- 效力：flk 返回 sxx=3（有效），公布 2012-12-28，施行 2013-07-01，是现行的 2012 修正本。
- 原文：第五十条「用人单位应当在解除或者终止劳动合同时出具解除或者终止劳动合同的证明，并在十五日内为劳动者办理档案和社会保险关系转移手续。」「劳动者应当按照双方约定，办理工作交接。用人单位依照本法有关规定应当向劳动者支付经济补偿的，在办结工作交接时支付。」
- 原文：第八十九条「用人单位违反本法规定未向劳动者出具解除或者终止劳动合同的书面证明，由劳动行政部门责令改正；给劳动者造成损害的，应当承担赔偿责任。」
- 原文：第九十一条「用人单位招用与其他用人单位尚未解除或者终止劳动合同的劳动者，给其他用人单位造成损失的，应当承担连带赔偿责任。」
- 写法上的取舍：「新单位要看离职证明」没有找到直接规定，所以条目只写第九十一条的连带责任，并说离职证明是「已经解除合同的书面凭据」，不写「新单位一定会要」。

## 2. 劳动合同法实施条例（第二十四条）
- URL：<https://flk.npc.gov.cn/detail?id=ff8080816f3cbb3c016f40927caf049c>
- 效力：sxx=3（有效），国务院令第 535 号，2008-09-18 公布施行。
- 原文：「用人单位出具的解除、终止劳动合同的证明，应当写明劳动合同期限、解除或者终止劳动合同的日期、工作岗位、在本单位的工作年限。」
- 四样里没有离职原因，备注里「条例要求写的四样里没有离职原因」即据此。

## 3. 失业保险条例（第十六条）
- URL：<https://xzfg.moj.gov.cn/front/law/detail?LawID=517>（司法部行政法规库）；flk 检索 sxx=3（有效），1999-01-22。
- 原文：「城镇企业事业单位应当及时为失业人员出具终止或者解除劳动关系的证明，告知其按照规定享受失业保险待遇的权利，并将失业人员的名单自终止或者解除劳动关系之日起7日内报社会保险经办机构备案。」「城镇企业事业单位职工失业后，应当持本单位为其出具的终止或者解除劳动关系的证明，及时到指定的社会保险经办机构办理失业登记。失业保险金自办理失业登记之日起计算。」
- 未核到：现在网上申领失业保险金时是否仍要上传这份证明。12333 办事指南页用无头 Chrome 取回为空。条目只写条例原文，不写「网上申领要不要传证明」。

## 4. 过程成本
- 劳动争议调解仲裁法（<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf64f28039d>，sxx=3）：第二条把「因订立、履行、变更、解除和终止劳动合同发生的争议」「因除名、辞退和辞职、离职发生的争议」列入适用范围；第二十七条「劳动争议申请仲裁的时效期间为一年」；第四十三条受理后「四十五日内结束」「延长期限不得超过十五日」；第五十三条「劳动争议仲裁不收费」。
- 劳动保障监察条例第十七条（<https://www.gov.cn/gongbao/content/2004/content_63042.htm>）：「应当自立案之日起60个工作日内完成；对情况复杂的……可以延长30个工作日」。
- 诉讼费用交纳办法（国务院令第 481 号）：第六条列的诉讼费用只有案件受理费、申请费和证人等出庭费用，不含律师费；第十三条第（四）项「劳动争议案件每件交纳10元」；第二十九条「诉讼费用由败诉方负担」。
- 「损失要你自己拿证据证明」是按第八十九条「给劳动者造成损害的」推出来的写法，没有引具体判例。

## 5. 财税〔2018〕164 号（第五条第（一）项、第八条、第九条）
- URL：<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202364/content.html>（国家税务总局政策法规库）；成文日期 2018-12-27。
- 原文：第五条第（一）项「个人与用人单位解除劳动关系取得一次性补偿收入（包括用人单位发放的经济补偿金、生活补助费和其他补助费），在当地上年职工平均工资3倍数额以内的部分，免征个人所得税；超过3倍数额的部分，不并入当年综合所得，单独适用综合所得税率表，计算纳税。」
- 原文：第八条「除上述衔接事项外，其他个人所得税优惠政策继续按照原文件规定执行。」第九条「本通知自2019年1月1日起执行。」第九条同时废止了财税〔2001〕157 号第一条、国税发〔1999〕178 号、国税发〔2000〕77 号。
- 执行期限：第一条（全年一次性奖金）、第二条（上市公司股权激励）原文带「在2021年12月31日前」；第五条第（一）项没有任何期限字样。
- 效力状态：法规库页面没有显示效力标注（「注释」弹窗在静态页和无头 Chrome 渲染后都是空的）。按全文判断：第五条第（一）项无截止日期；后续的财政部 税务总局公告 2023 年第 30 号（<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211524/content.html>）只延续全年一次性奖金，原文「本公告执行至2027年12月31日」，没有提到解除劳动关系补偿。在法规库按「解除劳动关系取得一次性补偿收入」「经济补偿金 个人所得税」检索，没有检到废止或修改这一项的文件。
- 财税〔2001〕157 号（<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202764/content.html>）第二条仍有效：补偿收入里按规定实际缴纳的住房公积金、医疗保险费、基本养老保险费、失业保险费，可以在计税时扣除。这一项用到的人少，没写进条目。

## 6. 个人所得税法（第三、九条，税率表一）
- URL：<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf724bd0609>；sxx=3（有效），2018-08-31 公布，2019-01-01 施行。
- 原文：第三条「综合所得，适用百分之三至百分之四十五的超额累进税率」；税率表一「不超过36000元的」3%，「超过36000元至144000元的部分」10%，「超过144000元至300000元的部分」20%，「超过300000元至420000元的部分」25%。第九条「以支付所得的单位或者个人为扣缴义务人」。
- 例子的算法：超出 3 倍的 6 万元，36000×3% + 24000×10% = 1080 + 2400 = 3480 元。整笔 36 万元按同一张表：36000×3% + 108000×10% + 156000×20% + 60000×25% = 1080 + 10800 + 31200 + 15000 = 58080 元。

## 没有写进去的
- 代通知金（第 5 条）和违法解除赔偿金（第 6 条，2N）算不算「一次性补偿收入」：164 号只点名了经济补偿金、生活补助费和其他补助费。在法规库检索「违法解除劳动合同 赔偿金」「代通知金」，没有检到总局的文件或答复。条目备注只写「文件没有单独点名，拿不准打 12366 问当地税务局」，不下结论。
- 「当地上年职工平均工资」具体用哪个口径（城镇非私营单位还是全口径、省还是市）：文件没有定义，条目写「以当地税务局为准」。
- 「个人所得税 App 能查到每笔收入的申报明细」是作者经验，只放在成本栏，没有写成收益。

## 收益量级与证据等级
- 第 17 条：证据 A（法律、行政法规原文）。收益定「中」、口径「金钱」。证明本身不直接换来钱，它保住的是按时办失业登记。失业保险金从登记那天起算，晚一个月就少一个月，单月金额按各省标准是数百到数千元一档，落在「中」。第八十九条的赔偿要你举证损失，数额说不准，不据此拔高。
- 第 18 条：证据 A（财税文件和法律原文）。收益定「大」、口径「金钱」，按收益栏的例子机械套：36 万元补偿，有这条优惠交 3480 元，整笔按税率表算是 58080 元，差 54600 元，是万元级。补偿金额小、不到 3 倍线的人，差额要看单位有没有把它错并进工资，这一档的人收益更小。
